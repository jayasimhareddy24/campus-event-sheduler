# Campus Event Scheduler

A simple web-based Campus Event Scheduler that helps students and campus communities view and manage upcoming events in an organized way.

## 📌 About the Project

The Campus Event Scheduler is a frontend web project designed to provide an easy-to-use interface for displaying and managing campus events.

Users can interact with the website to view scheduled events and use the available features through a clean and responsive interface.

## 🚀 Features

- 📅 Display campus events
- ➕ Add and manage events
- 🕒 View event dates and times
- 📍 Display event information
- 🎨 Clean and user-friendly interface
- 📱 Responsive web design
- ⚡ Interactive functionality using JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub
